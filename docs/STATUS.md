# Artiary — Offline Artifact Manager

Artifact management system for offline Docker development environments. Pre-downloads, version-pins, and caches Docker images, apt packages, npm/pip packages, and script binaries so the `docker-llm-cli` image can be built in air-gapped environments. Python 3.13, managed with `uv`.
